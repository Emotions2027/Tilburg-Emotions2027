# Emotions 2027 — Tilburg University

Static conference website for **Emotions 2027**, October 6–8, 2027, Tilburg University.

## Publish with GitHub Pages

1. Create a new public GitHub repository named `emotions-2027`.
2. Upload all files in this folder to the repository root (or push them with Git).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. After GitHub finishes the deployment, the site will be available at `https://YOUR-USERNAME.github.io/emotions-2027/`.

## Editing content

Each page is a plain `.html` file. Shared styling is in `assets/css/styles.css`; the small mobile-navigation script is in `assets/js/site.js`.

## Images and branding

The draft uses Creative Commons images from Wikimedia Commons for the Tilburg University campus and Cobbenhagen Building, with on-page attribution. Before the official launch, you may replace these with approved Tilburg University conference/campus photography. Tilburg University’s public science-communication guidance recommends using the corporate visual identity and checking image rights before publication.

The site deliberately does not bundle Tilburg University’s proprietary Scala Sans font or an unofficial copy of the institutional logo. If you have an approved web logo asset, it can be added easily.
